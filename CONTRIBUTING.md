# Contributing to scaracom

The following is a set of guidelines for contributing to **scaracom** and its package, which are hosted in the [scaracom](https://github.com/vroncevic/scaracom) on GitHub. These are mostly guidelines, not rules. Use your best judgment, and feel free to propose changes to this document in a pull request.

## Code of Conduct

**scaracom** project and everyone participating in it is governed by the [scaracom code of conduct](CODE_OF_CONDUCT.md). By participating, you are expected to uphold this code. Please report unacceptable behavior to [scaracom](mailto:elektron.ronca@gmail.com).
